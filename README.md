# HR Data Analysis using MySQL

## Project Overview

This project analyses a Human Resources dataset using SQL.

The project includes:

- Data Cleaning
- Data Analysis
- Business Insights

## Technologies

- MySQL Workbench
- SQL
- Git
- GitHub

## Files

- `HR_Data_Cleaning.sql`
- `HR_Data_Questions.sql`
- `Human Resources.csv`

## Business Questions

1. Gender breakdown
2. Race distribution
3. Age distribution
4. Headquarters vs Remote employees
5. Average employment length
6. Gender distribution across departments
7. Job title distribution
8. Department turnover rate
9. Employee distribution by state
10. Employee count changes over time
11. Department tenure distribution
